# Processos

Documentos que explicam **como** o time chegou a alguma decisão ou executou
algum processo — não é o resultado em si (isso fica em `planejamento/` ou
`sprints/`), é o raciocínio e os passos por trás dele. Exemplos: como o banco
foi provisionado no Supabase, como as migrations são rodadas, como uma
decisão de arquitetura foi tomada e por quê.
